# Milestone 1 Prompt

Implement the first vertical slice: authentication and manual Notes.

Requirements: email/password registration and login, secure password hashing, server-side user identity, sessions, user-isolation tests, task/reference notes, CRUD, one folder, multiple tags, pin, due date, priority, done, global ordering, history, search, versioned sync, optimistic concurrency, and conflict persistence.

Build responsive Notes UI with folder/tag controls, task checkbox, pin, editing, and drag reorder. Add D1 migrations, shared types, API validation, tests, and documentation.

Do not implement email connectors, calendar providers, named webhooks, AI, Tauri, or Android yet.
